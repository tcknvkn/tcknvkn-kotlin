# Testler

Bu dizin, `tcknvkn-kotlin` kütüphanesi için test kapsamını açıklar.

## Kapsam

- Tekil TCKN doğrulama senaryoları
- Toplu TCKN doğrulama senaryoları
- Tekil VKN doğrulama senaryoları
- Toplu VKN doğrulama senaryoları
- Normalize etme ve hata mesajı doğrulamaları

## Çalıştırma

```bash
gradle test
```
